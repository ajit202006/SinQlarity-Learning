# SinQlarity-Learning
This repo is created during a training program at SinQlarity. 
This repo contains all the topics and projects that are studied and developed in the training.
This training is completely done using agile methodoligies and working in sprints, using jira for achieving this.
Also the use of postman application is done to test backend APIs.
The backend technology being practiced was Express.js and all the backend applications are developed using REST API architecture.
Technologies used for frontend developement are html,css and js for beginner projects and react for end projects like todo app and quiz app.
Fetch apis are used to integrate backend and frontend together.
Beginner projects were developed using javascript and then shifted to typescript to write more consistent and less buggy code.
This is the overview of this training program all the work done during this is present in the github repo where you can get idea of everything we learnt.
